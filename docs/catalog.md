# S1：工具目录快照

输入是一组明确投影后的工具记录：serverId、name、description、inputSchema。未知顶层字段拒绝；完整 MCP 广告的其它字段应由未来的适配器单独保留，不能声称这里就是无损 MCP 代理。

- 身份为 serverId::name，组件只允许字母、数字、下划线、点与连字符；不同服务的同名工具不会冲突。
- 拒绝重复身份、空描述、非有限数、undefined、BigInt、访问器、循环、稀疏数组与非普通对象。
- 输入 Schema 必须是 type: object 的 JSON 对象；这里只做 JSON 结构校验，不校验完整 Schema 语义或调用参数。
- 工具排序、对象键排序后计算 SHA-256，保留 Schema 数组顺序。
- 快照深拷贝并冻结；调用方修改原对象不改变已建立的目录。
- 上限：1000 工具、每项 10000 JSON 节点、32 层深度、描述 8000 字符、目录有效负载 2 MiB。
- 遍历过程中累计字符串和键的字节预算，避免先构造巨大序列化结果再拒绝；它仍不是整个进程的内存沙箱。

digest 只是目录内容标识，不代表用户授权、进程安全或实时可用性。权限、状态和执行结果不进入本层判断。

验证：tests/catalog.test.ts。格式等价、变化敏感、输入隔离、无效数据和原型键均有离线测试。
