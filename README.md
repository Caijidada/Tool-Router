# Agent Tool Router

项目 B 的独立实现，工作名尚未查重。不绑定 REA 或某一家模型；目标是在 Agent 调用工具前，提供可拒选、可回退、可验证的工具推荐。

**当前阶段：工程骨架。尚未接入 MCP、REA 或 Jev，不会执行工具或发送远程模型请求。**

## 本地使用

需要 Node.js 24 与 npm。

```sh
npm ci --ignore-scripts
npm run check
npm run demo
```

## 核心原则

- 模型推荐不等于用户授权。策略、参数验证与执行前检查独立于评分器。
- 没有合适工具、状态未知、模型失败均应显式返回，不强行选择第一名。
- 缺少前置资源不等于永远不可用；需要前置步骤的工具与立即可用工具分开。
- Jev 是后续可选的决策提供者，不是不可替换的产品基础。
- 不宣称完整 Agent、通用沙箱或已经测得成本收益。

## 开源与归属

目前是原创的最小伴生项目骨架，不是对某个完整仓库的换名 Fork。后续优先复用成熟 SDK 和现成代理中合适的部分，明确记录来源与修改范围。package 标记为 private，不发布 npm 包。许可证和公开范围待仓库所有者决定，当前不授予开源再分发许可。
